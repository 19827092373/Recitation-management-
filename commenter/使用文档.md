## 📖 项目简介

**AI 学生评语助手**是一款专为教师设计的智能评语生成工具。通过 AI 技术，帮助教师快速、高效地为学生生成个性化、有温度的期末评语，大幅提升工作效率，让评语写作从繁琐重复的工作中解放出来。

### 核心优势

- ✨ **AI 驱动**：基于先进的大语言模型，生成自然流畅、个性化的评语
- 🚀 **批量处理**：支持一次性为全班学生生成评语，效率提升 10 倍以上
- 🎯 **精准定制**：通过标签系统，为每个学生定制专属评语内容
- 📊 **数据管理**：支持 Excel 导入导出，轻松管理学生信息
- 💾 **本地存储**：数据保存在浏览器本地，安全可靠
- 🎨 **界面友好**：简洁直观的操作界面，无需培训即可上手

## 👥 使用对象

### 主要用户群体

#### 1. **中小学班主任**
- **使用场景**：每学期末需要为全班学生撰写评语
- **痛点解决**：
  - 传统方式需要逐字逐句编写，耗时耗力
  - 评语容易千篇一律，缺乏个性化
  - 需要记住每个学生的特点，容易遗漏
- **使用价值**：将评语写作时间从数小时缩短至数分钟，同时保证质量

#### 2. **学科教师**
- **使用场景**：需要为所教班级学生写学科评语
- **痛点解决**：
  - 跨班级教学，学生信息管理困难
  - 需要突出学科特点，评语要求更专业
- **使用价值**：快速生成符合学科特色的评语

#### 3. **年级组长 / 德育主任**
- **使用场景**：需要审核或协助多个班级的评语工作
- **痛点解决**：
  - 需要统一评语风格和质量标准
  - 需要快速了解各班级评语完成情况
- **使用价值**：统一评语模板，提高整体评语质量

#### 4. **实习教师 / 新教师**
- **使用场景**：缺乏评语写作经验，需要参考和指导
- **痛点解决**：
  - 不知道如何写评语，缺乏经验
  - 评语写作不规范，需要模板参考
- **使用价值**：提供专业的评语模板和生成逻辑，快速上手

### 适用场景

- ✅ 期末评语撰写
- ✅ 学期总结评语
- ✅ 学生成长档案记录
- ✅ 家长会材料准备
- ✅ 学生综合素质评价

## ✨ 功能特性

### 1. 学生名单管理

#### 导入学生名单
- **文本导入**：直接粘贴学生姓名（每行一个）
- **Excel 导入**：支持从 Excel 文件导入学生信息
- **自动排序**：导入后自动按姓名排序，并分配成绩档位

#### 学生信息编辑
- 修改学生姓名
- 设置学生性别（男/女）
- 调整成绩档位（卓越/优秀/中等/中下/后进）
- 添加/删除学生

### 2. 特征标签系统

#### 性格特征
预设标签包括：活泼开朗、文静内敛、踏实稳重、思维活跃、自信大方、谦逊有礼、坚毅果敢、自律性强等 20+ 种性格标签。

#### 行为表现
预设标签包括：积极举手、听讲专注、勤于思考、笔记详实、字迹工整、喜爱阅读、乐于助人、纪律性强等 20+ 种行为标签。

#### 参与活动
预设标签包括：校运会接力、校园十佳歌手、科技节水火箭、机器人编程、黑板报设计、爱心义卖等 30+ 种活动标签。

#### 自定义标签
- 支持添加自定义的性格、行为、活动标签
- 标签可随时编辑和删除
- 标签可在多个学生间批量应用

### 3. AI 评语生成

#### 批量生成
- 一键为选中学生生成评语
- 实时显示生成进度
- 支持中断和重新生成

#### 单个生成
- 为单个学生单独生成评语
- 支持重新生成，直到满意为止

#### 评语特点
- **个性化**：每个学生的评语都是独特的，避免雷同
- **有温度**：评语语言自然流畅，富有感情色彩
- **有文化**：自动融入诗词、名言或成语
- **有画面感**：用具体行为描述代替空洞形容词
- **拒绝套路**：避免"该生"、"领头羊"等固定套话

### 4. 数据导出

#### Excel 导出
- 导出学生名单和评语到 Excel 文件
- 包含学生姓名、性别、成绩档位、特征标签、评语内容
- 方便后续编辑和打印

#### 批量操作
- 全选/取消全选学生
- 批量设置特征标签
- 批量调整成绩档位

### 5. 系统配置

#### AI 模型配置
- 支持自定义 AI 模型 API（如 DeepSeek、OpenAI、Claude 等）
- 配置 API Base URL 和 API Key
- 支持测试 API 连接

#### 评语模板自定义
- 可自定义评语生成模板
- 支持变量替换（姓名、性别、成绩、特征、活动等）
- 可设置评语风格和要求

## 🚀 快速开始

### 第一步：访问系统

打开浏览器，访问：**https://recitation.teacherlab.cn/commenter**

### 第二步：配置 AI API

1. 点击左侧菜单的 **"系统配置"**
2. 填写以下信息：
   - **Base URL**：AI 模型的 API 地址（默认：`https://api.deepseek.com/v1`）
   - **API Key**：你的 API 密钥
   - **Model**：模型名称（默认：`deepseek-chat`）
3. 点击 **"测试 API"** 按钮，确认连接成功

### 第三步：导入学生名单

1. 点击 **"导入名单"** 按钮
2. 选择导入方式：
   - **文本导入**：在文本框中输入学生姓名，每行一个
   - **Excel 导入**：选择 Excel 文件（第一列应为学生姓名）
3. 点击 **"确认导入"**

### 第四步：设置学生特征

1. 点击左侧菜单的 **"特征分配"**
2. 选择要设置的特征类型（性格/行为/活动）
3. 点击学生卡片，为其添加特征标签

### 第五步：生成评语

1. 返回 **"名单管理"** 页面
2. 选择要生成评语的学生（可全选）
3. 点击 **"批量生成评语"** 按钮
4. 等待生成完成（通常需要 1-3 分钟）

### 第六步：导出评语

1. 生成完成后，点击 **"导出 Excel"** 按钮
2. 下载的文件包含所有学生信息和评语
3. 可在 Excel 中进一步编辑和打印

## 📚 详细使用方法

### 一、学生名单管理

#### 1.1 导入学生名单

**方法一：文本导入**
1. 点击顶部工具栏的 **"👥 导入名单"** 按钮
2. 在弹出的对话框中，选择 **"文本导入"** 标签
3. 在文本框中输入学生姓名，每行一个，例如：
   ```
   张三
   李四
   王五
   ```
4. 点击 **"确认导入"** 按钮

**方法二：Excel 导入**
1. 点击 **"👥 导入名单"** 按钮
2. 选择 **"Excel 导入"** 标签
3. 点击 **"选择文件"**，选择包含学生姓名的 Excel 文件
4. 系统会自动识别第一列的学生姓名
5. 点击 **"确认导入"**

**注意事项**：
- 导入的学生会按照姓名自动排序
- 系统会根据排序位置自动分配成绩档位（前 20% 为卓越，以此类推）
- 导入后可以手动调整每个学生的成绩档位

#### 1.2 添加单个学生

1. 点击顶部工具栏的 **"➕ 添加学生"** 按钮
2. 在弹出的对话框中输入学生姓名
3. 选择学生性别
4. 选择成绩档位
5. 点击 **"确认添加"**

#### 1.3 编辑学生信息

1. 在学生卡片上，点击 **"编辑"** 按钮（铅笔图标）
2. 修改学生姓名、性别或成绩档位
3. 点击 **"保存"** 确认修改

#### 1.4 删除学生

1. 点击学生卡片上的 **"删除"** 按钮（垃圾桶图标）
2. 确认删除操作

#### 1.5 批量操作

**全选/取消全选**：
- 点击顶部工具栏的 **"全选"** 按钮，选中所有学生
- 再次点击可取消全选

**批量设置特征**：
1. 先选择要操作的学生（可多选）
2. 在特征标签区域，点击标签即可批量添加/移除该特征

**批量调整成绩档位**：
1. 选择要调整的学生
2. 点击顶部工具栏的成绩档位下拉菜单
3. 选择新的档位，批量更新

### 二、特征标签管理

#### 2.1 查看特征标签

1. 点击左侧菜单的 **"特征分配"**
2. 在顶部选择要查看的特征类型：
   - **参与活动**：学生参与的各种活动
   - **性格特征**：学生的性格特点
   - **行为表现**：学生的学习习惯和行为表现

#### 2.2 为学生添加特征标签

**方法一：在学生卡片上添加**
1. 在 **"名单管理"** 页面，点击学生卡片
2. 在弹出的详情中，点击 **"添加特征"** 按钮
3. 选择要添加的特征标签

**方法二：批量添加**
1. 先选择多个学生（可多选）
2. 在特征标签区域，点击标签即可批量添加

#### 2.3 移除特征标签

1. 在学生卡片上，点击已添加的特征标签的 **"×"** 按钮
2. 或选择多个学生后，点击标签批量移除

#### 2.4 自定义特征标签

1. 进入 **"特征分配"** 页面
2. 选择要添加自定义标签的类型（活动/性格/行为）
3. 点击 **"➕ 添加自定义"** 按钮
4. 输入标签名称，点击确认
5. 自定义标签会出现在标签列表中，可以像预设标签一样使用

#### 2.5 删除自定义标签

1. 在 **"特征分配"** 页面
2. 找到要删除的自定义标签
3. 点击标签右侧的 **"删除"** 按钮
4. 注意：删除标签不会影响已为学生添加的该标签

### 三、AI 评语生成

#### 3.1 单个学生评语生成

1. 在学生卡片上，点击 **"生成评语"** 按钮（魔法棒图标）
2. 系统会调用 AI 生成评语
3. 生成完成后，评语会显示在学生卡片上
4. 如果不满意，可以点击 **"重新生成"** 按钮

#### 3.2 批量生成评语

1. 选择要生成评语的学生（可全选）
2. 点击顶部工具栏的 **"批量生成评语"** 按钮
3. 系统会显示生成进度（当前进度/总人数）
4. 生成过程中可以随时中断
5. 生成完成后，所有学生的评语都会显示在卡片上

#### 3.3 评语编辑

生成后的评语可以直接在学生卡片上编辑：
1. 点击评语内容区域
2. 直接修改文本
3. 修改会自动保存

#### 3.4 评语状态

每个学生的评语有以下状态：
- **待生成**：还没有生成评语
- **生成中**：正在生成评语
- **已完成**：评语已生成
- **生成失败**：生成过程中出错，可以重新生成

### 四、数据导出

#### 4.1 导出为 Excel

1. 点击顶部工具栏的 **"📊 导出 Excel"** 按钮
2. 系统会自动下载一个 Excel 文件
3. 文件包含以下列：
   - 学生姓名
   - 性别
   - 成绩档位
   - 特征标签（用逗号分隔）
   - 评语内容

#### 4.2 导出后的处理

导出的 Excel 文件可以：
- 在 Excel 中进一步编辑评语
- 调整格式和排版
- 打印成纸质评语
- 导入到其他系统

### 五、系统配置

#### 5.1 AI 模型配置

1. 点击左侧菜单的 **"系统配置"**
2. 在 **"AI 模型设置"** 区域填写：
   - **Base URL**：AI 模型的 API 地址
     - DeepSeek：`https://api.deepseek.com/v1`
     - OpenAI：`https://api.openai.com/v1`
     - 其他兼容 OpenAI 格式的 API
   - **API Key**：你的 API 密钥
   - **Model**：模型名称
     - DeepSeek：`deepseek-chat`
     - OpenAI：`gpt-3.5-turbo` 或 `gpt-4`
3. 点击 **"测试 API"** 按钮，确认配置正确
4. 配置会自动保存

#### 5.2 评语模板自定义

1. 在 **"系统配置"** 页面，找到 **"评语模板"** 区域
2. 在文本框中编辑模板内容
3. 可以使用以下变量：
   - `{{name}}`：学生姓名
   - `{{gender}}`：学生性别（男/女）
   - `{{rank_label}}`：成绩档位描述
   - `{{traits}}`：特征标签（用顿号分隔）
   - `{{projects}}`：参与活动（用顿号分隔）
4. 点击 **"保存模板"** 按钮

**默认模板示例**：
```
你是一位拥有20年教龄的资深班主任。请为学生{{name}}同学撰写期末评语。

【学生信息】
- 性别：{{gender}}
- 成绩概况：{{rank_label}}
- 性格与习惯：{{traits}}
- 参与活动：{{projects}}

【写作要求】
1. **称谓正式**：必须以"{{name}}同学"开头。
2. **严禁编造**：如果"参与活动"为空，绝对不要编造任何活动经历。
3. **字数限制**：控制在100字左右。
4. **文化底蕴**：请根据学生特点，自然融入一句贴切的诗词、名言或成语。
5. **拒绝平庸**：不要使用"该生"、"领头羊"等固定套话。
```

## ⚙️ 配置说明

### API 配置

#### DeepSeek API（推荐）

1. **注册账号**：访问 https://platform.deepseek.com 注册账号
2. **获取 API Key**：在控制台中创建 API Key
3. **配置信息**：
   - Base URL：`https://api.deepseek.com/v1`
   - Model：`deepseek-chat`
   - API Key：你的 DeepSeek API Key

#### OpenAI API

1. **注册账号**：访问 https://platform.openai.com 注册账号
2. **获取 API Key**：在 API Keys 页面创建新的 Key
3. **配置信息**：
   - Base URL：`https://api.openai.com/v1`
   - Model：`gpt-3.5-turbo` 或 `gpt-4`
   - API Key：你的 OpenAI API Key

#### 其他兼容 API

如果使用其他兼容 OpenAI 格式的 API（如本地部署的模型），只需：
- 填写对应的 Base URL
- 填写对应的 Model 名称
- 填写 API Key（如果需要）

### 数据存储

- 所有数据（学生名单、特征标签、评语、配置）都保存在浏览器本地存储中
- 数据不会上传到任何服务器
- 清除浏览器缓存会清除数据，建议定期导出备份

### 浏览器要求

- 推荐使用 Chrome、Edge、Firefox 等现代浏览器
- 需要启用 JavaScript
- 需要允许本地存储（localStorage）

## ❓ 常见问题

### Q1: 如何获取 API Key？

**A**: 
- **DeepSeek**：访问 https://platform.deepseek.com，注册后即可获取免费额度
- **OpenAI**：访问 https://platform.openai.com，注册后购买额度
- 其他 API 提供商：参考其官方文档

### Q2: API 调用失败怎么办？

**A**: 请检查以下几点：
1. Base URL 是否正确
2. API Key 是否有效
3. 网络连接是否正常
4. API 额度是否充足
5. 点击"测试 API"按钮查看详细错误信息

### Q3: 生成的评语不满意怎么办？

**A**: 
1. 点击"重新生成"按钮，可以多次生成直到满意
2. 手动编辑评语内容
3. 调整学生的特征标签，重新生成
4. 修改评语模板，改变生成风格

### Q4: 数据会丢失吗？

**A**: 
- 数据保存在浏览器本地，清除浏览器缓存会丢失数据
- **建议**：定期导出 Excel 文件作为备份
- 更换浏览器或电脑时，需要重新导入数据

### Q5: 可以离线使用吗？

**A**: 
- 可以离线查看和编辑已生成的数据
- 但生成评语需要联网调用 AI API

### Q6: 支持多少学生？

**A**: 
- 理论上没有限制
- 建议单次批量生成不超过 50 人，以保证生成速度
- 如果学生很多，可以分批生成

### Q7: 评语可以自定义格式吗？

**A**: 
- 可以！在"系统配置"中可以自定义评语模板
- 支持变量替换，可以灵活调整格式和内容

### Q8: 可以导出 Word 格式吗？

**A**: 
- 目前支持导出 Excel 格式
- 导出的 Excel 文件可以在 Word 中打开和编辑
- 或者复制评语内容到 Word 中

### Q9: 特征标签不够用怎么办？

**A**: 
- 可以添加自定义标签
- 在"特征分配"页面点击"添加自定义"按钮
- 自定义标签会保存，下次使用时仍然存在

### Q10: 生成的评语会重复吗？

**A**: 
- 系统设计了防重复机制，每个学生的评语都是独特的
- 如果发现重复，可以重新生成
- 建议为每个学生设置不同的特征标签，以保证评语的个性化

## 🔧 技术说明

### 技术栈

- **前端框架**：Next.js 16 + React 19
- **UI 组件**：Tailwind CSS + Lucide Icons
- **状态管理**：Zustand（带持久化存储）
- **数据处理**：XLSX（Excel 导入导出）
- **AI 集成**：兼容 OpenAI API 格式的大语言模型

### 部署信息

- **访问地址**：https://recitation.teacherlab.cn/commenter
- **部署方式**：静态网站部署（Next.js 静态导出）
- **自动部署**：GitHub Actions 自动部署到阿里云 ECS

### 数据安全

- 所有数据存储在浏览器本地（localStorage）
