# 部署配置说明

## 📋 概述

本项目是 **Next.js 静态导出**的网站，部署在子目录 `/commenter` 下。本文档说明部署后是否需要额外的服务器配置。

---

## ✅ 默认配置（通常不需要额外配置）

### 情况一：使用宝塔面板 / 一键部署工具

**✅ 无需额外配置！**

如果你的服务器使用宝塔面板或其他一键部署工具，通常已经配置好了 Nginx/Apache，**直接部署即可使用**。

部署后访问：`https://recitation.teacherlab.cn/commenter`

### 情况二：标准 Nginx 配置

如果你的服务器使用标准的 Nginx 配置，通常也**无需额外配置**，因为：

1. ✅ Next.js 静态导出会生成标准的 HTML/CSS/JS 文件
2. ✅ 文件已部署到正确路径：`/www/wwwroot/recitation.teacherlab.cn/commenter`
3. ✅ Nginx 默认会正确提供静态文件

---

## ⚙️ 如果需要手动配置 Nginx

### 检查当前配置

如果你的网站无法正常访问，可能需要检查 Nginx 配置。以下是推荐的配置：

### Nginx 配置示例

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name recitation.teacherlab.cn;
    
    # SSL 证书配置（如果有）
    # ssl_certificate /path/to/cert.pem;
    # ssl_certificate_key /path/to/key.pem;
    
    root /www/wwwroot/recitation.teacherlab.cn;
    index index.html index.htm;
    
    # 主站点配置
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # commenter 子目录配置
    location /commenter {
        alias /www/wwwroot/recitation.teacherlab.cn/commenter;
        try_files $uri $uri/ /commenter/index.html;
        
        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
    
    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
}
```

### 配置说明

1. **`location /commenter`**：处理 `/commenter` 路径的请求
2. **`alias`**：指向实际的部署目录
3. **`try_files`**：确保客户端路由正常工作（Next.js 使用客户端路由）
4. **静态资源缓存**：优化加载速度

### 应用配置

```bash
# 1. 编辑 Nginx 配置文件
sudo nano /etc/nginx/sites-available/recitation.teacherlab.cn
# 或
sudo nano /etc/nginx/conf.d/recitation.teacherlab.cn.conf

# 2. 将上面的配置添加到文件中（根据实际情况调整）

# 3. 测试配置
sudo nginx -t

# 4. 重载 Nginx
sudo systemctl reload nginx
# 或
sudo service nginx reload
```

## 🔍 验证部署

### 1. 检查文件是否存在

SSH 连接到服务器，检查文件：

```bash
# 检查部署目录

# 应该看到以下文件：
# - index.html
# - _next/ (目录)
```

```bash
# 确保 Nginx 用户可以读取文件

chown -R nginx:nginx /www/wwwroot/recitation.teacherlab.cn/commenter
```

- `https://recitation.teacherlab.cn/commenter`

两者都应该能正常访问。

## 🐛 常见问题排查

### 问题 1：404 错误

**症状**：访问 `/commenter` 返回 404

**解决方法**：
1. 检查文件是否已正确部署
2. 检查 Nginx 配置中的路径是否正确
3. 检查文件权限

### 问题 2：页面空白 / 资源加载失败

**症状**：页面打开但显示空白，或控制台报错资源加载失败

**解决方法**：
1. 检查 `basePath` 配置是否正确（应为 `/commenter`）
2. 检查浏览器控制台的错误信息
3. 确认 `_next/static/` 目录下的资源可以正常访问

### 问题 3：路由跳转失败

**症状**：点击页面内链接后返回 404

**解决方法**：
1. 确保 Nginx 配置中有 `try_files` 规则
2. 检查 `basePath` 配置是否正确

### 问题 4：CSS/JS 文件 404

**症状**：页面显示但没有样式，或功能不工作

**解决方法**：
1. 检查 `_next/static/` 目录是否存在
2. 检查文件权限
3. 检查浏览器控制台的网络请求，看资源路径是否正确
