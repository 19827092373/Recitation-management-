# AI 学生评语生成器

基于 Next.js 和 AI 的学生评语自动生成工具。

## 功能特性

- AI 驱动的评语生成
- 批量学生管理
- Excel 导入/导出
- 响应式设计

## 快速开始

```bash
npm install
npm run dev
```

访问 [http://localhost:3000/commenter](http://localhost:3000/commenter)

## 部署说明

本项目作为子项目部署在原有仓库中。

- 访问地址：`https://recitation.teacherlab.cn/commenter`
- 部署路径：`/www/wwwroot/recitation.teacherlab.cn/commenter`
- 文件夹名：`commenter`

推送代码到 `main` 分支后自动部署。
